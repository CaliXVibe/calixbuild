# Cookie / Consent Banner

**Text (bottom of every page):**

> We use essential cookies to run the site. No non-essential scripts load on this draft. [Privacy Policy](/privacy) · [Do Not Sell or Share](/do-not-sell)

**Buttons:** Accept · Opt out

**Behavior:** Choice is stored in `localStorage` (`calix-cookie-consent`). Opt out keeps non-essential scripts off. This draft does not load chat or analytics. Essential cookies for security and the site itself stay on.
